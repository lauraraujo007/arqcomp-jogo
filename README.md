# Jogos de Arquitetura Computacional

Dois jogos em uma página para treinar os termos da aula de Tópicos de Arquitetura Computacional.

**Site publicado:** https://SEU-USUARIO.github.io/arqcomp-cruzadinha/

## Como jogar

**Palavra embaralhada:** leia a pista, arrume as letras que aparecem bagunçadas e digite a palavra. Clique em *Conferir* para ver o que está certo ou errado e acompanhe o contador (ex.: "8 de 12 palavras"). *Reiniciar* embaralha tudo de novo.

**Ligar pistas e termos:** clique em um termo e depois na pista que combina com ele. Clique de novo para desfazer. *Conferir* mostra os pares certos e errados, e *Reiniciar* limpa tudo.

## Palavras e pistas

| Palavra | Pista |
|---|---|
| CPU | Cérebro do computador: busca, entende e executa as instruções dos programas. |
| ULA | Parte da CPU que faz as contas e as operações lógicas. |
| REGISTRADORES | Memórias minúsculas dentro da CPU, as mais rápidas de todas. |
| RAM | Memória de trabalho: guarda programas em uso, mas apaga ao desligar. |
| ROM | Memória só de leitura que guarda dados fixos e não apaga ao desligar. |
| EEPROM | Memória que guarda dados sem energia e permite regravar byte a byte com pulso elétrico. |
| FLASH | Memória sem energia, regravada em blocos, usada em pen drives e SSDs. |
| CACHE | Memória pequena e veloz perto da CPU que guarda o que é usado com frequência. |
| DMA | Permite que dispositivos troquem informações com a memória sem passar pela CPU. |
| DATABUS | Fios que transportam o conteúdo lido ou gravado entre CPU e memória. |
| DUALCORE | Um só chip com dois processadores completos trabalhando em conjunto. |
| QUADCORE | Um só chip com quatro processadores completos trabalhando em conjunto. |
